Pearson Correlation：曲线、收益率与中心化

同一对 symbol 可以同时出现“每日方向相反”和“收益率 correlation 为正”。关键不在绝对正负，而在每个观测相对各自均值的偏离是否同向。

打开研究文档
1选择输入变量价格 P，或 log return g = ln(Pt / Pt-1)
2分别减去均值dx = x - mean(x)，dy = y - mean(y)
3比较中心化偏离corr = Σ(dx·dy) / √[Σdx²·Σdy²]

选择案例

每个案例同时重算价格与 log return correlation。
