## Log Return

日 log return 的计算公式为：

\[
r_{s,t}=\ln\left(\frac{P_{s,t}}{P_{s,t-1}}\right)
\]

其中：

- \(s\) 表示证券，取值为 XLP 或 SMH；
- \(t\) 表示当前交易日；
- \(t-1\) 表示当前交易日之前的上一交易日；
- \(P_{s,t}\) 表示证券 \(s\) 在交易日 \(t\) 的拆股及分红调整后收盘价，价格单位为美元；
- \(r_{s,t}\) 表示证券 \(s\) 从 \(t-1\) 至 \(t\) 的日 log return，为无量纲数值；
- \(\ln\) 表示自然对数。
