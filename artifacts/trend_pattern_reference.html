Trend pattern 识别规则参考

基于 trend_pattern_v3 当前规则，阈值直接读取 config/settings.yaml。每幅模拟图由固定的分段 fitted log return 生成，并已通过使用同一套生产阈值的真实分类函数验证；它只展示一种典型触发路径，不代表该 pattern 的全部真实市场形态。

共同计算口径

方向段
abs(fitted_log_return) >= 0.02，并且 linearity_r2 >= 0.35 或 abs(vol_adjusted_trend) >= 0.75；否则为 flat。
有效 legs
从原始方向序列中去除 flat，并合并相邻同方向分段。
Q = net / gross
abs(sum(fitted returns)) / sum(abs(fitted returns))；至少 3 legs 且 Q <= 0.35 时进入 range 分支。
摆动相似度
relative_difference <= 0.25，等价于 similarity >= 0.75。
振幅变化
最小变化比例 0.15：收敛要求 current <= previous × 0.85；扩张要求 current >= previous × 1.15。
Double test 确认
confirmation >= max(reference amplitudes) × 0.5，并且摆动相似度同时达标。
规则优先级
无 leg → 单 leg → 双 leg → double test → range → 三 leg 趋势/复杂反转 → 多 leg。
up / 上涨down / 下跌flat / 横向

蜡烛是帮助理解拟合路径的确定性模拟数据。分类器实际使用分段指标，而不是直接根据蜡烛外观命名。

Irregular｜兜底
irregular_path
不规则路径（兜底）
irregular · bias=neutral, structure=mixed, terminal=—
无可达合法示例

初始化兜底值：当路径未命中任何受支持的几何规则时使用。当前有效 legs 会交替，且后续分支基本穷尽合法路径，因此正常、完整输入下没有可构造的可达示例。

保留该行是为了完整说明输出契约；不伪造一个无法通过当前分类函数验证的 K 线案例。
