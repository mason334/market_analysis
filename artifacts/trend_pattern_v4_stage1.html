分类依据

方向归一化
如果首腿向下，将全部 signed leg return 乘以 -1； 所有模板因此统一从 up 开始。
同类 pivot 比较
第 i 条腿完成后比较 Pᵢ 与 Pᵢ₋₂； 等价于比较当前腿与前一腿的绝对振幅。
relative difference
|Aᵢ − Aᵢ₋₁| / max(Aᵢ, Aᵢ₋₁)。 不超过 0.25 为 retest。
互斥区间
令 r = Aᵢ/Aᵢ₋₁： r < 0.750 为 short_of；0.750 ≤ r ≤ 1.333 为 retest；r > 1.333 为 break。
